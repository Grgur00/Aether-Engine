01 / Architecture

A database shaped like
your application.

Aether runs in the same process as your code. The public API stays small while the storage stack remains modular, inspectable, and independently testable.

A

Compile-time type safety

Define collections using Java types. Generated codecs produce deterministic wire formats and fail incompatible schema changes during the build—not after deployment.

record LedgerEntry(
  UUID accountId,
  long amountMinor,
  Instant bookedAt
) {}
B

Explicit durability

Group-synced writes reach the WAL before success becomes visible. Recovery verifies every acknowledged marker.

C

Stable snapshots

MVCC snapshots preserve a consistent sequence while foreground writes continue.

D

Atomic batches

Coordinate changes across typed collections with one all-or-nothing write batch.

E

Built for inspection

Checksummed blocks, deterministic formats, runtime metrics, crash fixtures, CLI tooling, and a visual Workbench.

02 / Quickstart

From checkout to
first durable write.

Aether artifacts are not published to Maven Central yet. During the pre-release, build applications as modules in a source checkout to keep versions aligned.

01

Get the source

Clone Aether and verify the Java 21 toolchain.

Terminal
git clone https://github.com/Grgur00/Aether-Engine.git
cd Aether-Engine
./gradlew check
02

Add your application module

Include a module in settings.gradle.kts, then depend on the supported typed surface.

your-app/build.gradle.kts
plugins { id("aether.java-application") }

dependencies {
    implementation(project(":modules:aether-api"))
    implementation(project(":modules:aether-codec"))
    implementation(project(":modules:aether-embedded-typed"))
    annotationProcessor(project(":modules:aether-codec-processor"))
}
03

Define a durable record

The processor generates its canonical codec and schema descriptor at compile time.

Todo.java
import io.aetherdb.codec.annotation.AetherRecord;

@AetherRecord(version = 1)
public record Todo(
        String id,
        String title,
        boolean completed) {}
04

Open, write, and read

The directory is created on first use and exclusively locked until close.

Main.java
try (var db = AetherEmbedded.open(Path.of("./data/app"))) {
    var collection = db.defineCollection(
            "todos", String.class, Todo.class);

    collection.put("ship",
            new Todo("ship", "Ship reliably", false));

    Todo todo = collection.get("ship").requireValue();
}
05

Accept the schema identity

Commit schema locks with your source. Later changes require an explicit update and acceptance.

Terminal
# First schema
./gradlew aetherSchemaInit
./gradlew aetherSchemaAccept

# After an intentional versioned change
./gradlew aetherSchemaUpdate
./gradlew aetherSchemaAccept
Commit aether-schemas/. It is the durable identity of your records: UUIDs, field IDs, bounds, retired fields, and fingerprints.
03 / Operations

Clear behavior at
the boundaries.

No hidden daemon and no remote control plane. Your process owns database lifetime, durability policy, and observability.

LIFETIME

One directory.
One writer.

AetherEmbedded.open(path) acquires an OS-backed exclusive lock. Close the application before opening the same data in Workbench.

DURABILITY

Success has a
specific meaning.

The default GROUP_SYNC mode forces the WAL before publishing a successful result. Write outcomes distinguish applied, rejected, and indeterminate states.

OBSERVABILITY

Metrics without
a monitoring stack.

Use the metered decorator for bounded p50, p95, and p99 latency, throughput, operation counts, failures, and error rate.

Metered API

Measure the path your users take.

Open a metered database directly or instrument an existing implementation. Reset the reservoir before controlled measurements.

  • 16,384 bounded samples per operation
  • No external monitoring dependency
  • GET, PUT, DELETE, batch, and scan visibility
Metrics.java
try (var db = Aether.openWithMetrics(path)) {
    db.put(key, value);
    db.get(key);

    var reads = db.metrics()
            .operation(DatabaseOperation.GET);

    System.out.printf("p99 %.3f ms%n",
            reads.p99LatencyMillis());
}
