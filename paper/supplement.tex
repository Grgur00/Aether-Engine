\section{Evidence files}
Each paired block retains V1/V2 manifests, population and training reports, command logs, protocol and environment identity, checksums and validated cache counters. Generated cache directories may be removed after successful evidence capture to bound disk use. Interrupted blocks are retained separately and rerun in full. The analysis does not treat a changed environment as the same replica series.

Generated Java and mmap stores can use a separately configured scratch filesystem. Reports remain under the saved output directory. A payload lower-bound capacity check precedes measurement, while metadata and temporary writes may require additional space. The runner records the scratch location, preserves failed attempts, and removes only its own completed store directory. Output locks prevent two GPU runners from owning the same campaign. Resume verifies the frozen protocol, source and environment before reusing completed observations.

\section{Failure semantics}
The controller waits for a marker written by the Java writer at the requested publication boundary before sending SIGKILL on POSIX or TerminateProcess on Windows. An application-side witness records returned API calls. Verification reopens the same engine and checks all expected visible artifacts and every acknowledged write. Orphans are measured separately. These experiments do not simulate loss of device power, storage-controller cache failure or malicious corruption.

\section{Statistical details}
The frozen primary endpoint is effective throughput across ten V2 training epochs in exactly 24 fresh paired OCT5K blocks. The sole primary test is TOST on log Aether/mmap ratios at $\alpha=0.05$, with ratio equivalence bounds 0.97 and 1.03. The exponentiated 90\% Student-$t$ interval must lie strictly within these bounds. RAW superiority is a secondary one-sided paired log-ratio test at $\alpha=0.05$; no Holm adjustment couples it to the primary decision. RAM is descriptive. Keep all pilot measurements separate and report every exclusion and failed run with its reason. Cumulative epoch 1--10 curves use the same blocks and remain secondary. The detailed timing scope and immutable settings are specified in \texttt{kaggle/CONFIRMATORY.md}. Bootstrap resampling preserves complete pairs; any mixed-effects analysis belongs to separate exploratory matrix campaigns.
